# Conversations

Conversaciones completas (verbatim) que valen la pena conservar tal cual —
no toda conversación, solo las que tienen ida-y-vuelta rico, conceptos que se
perderían al resumir, o contenido híbrido personal/negocio inseparable.

Usa `_template.md` como encabezado y pega el contenido completo o los tramos
con sustancia debajo.
